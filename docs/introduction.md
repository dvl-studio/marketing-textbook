# 編寫說明

本書將 13 份原始文獻重排為一條可以連續閱讀的知識路徑：先理解人如何接收訊息、形成態度與意圖，再進入注意力、選擇架構與創新擴散，接著處理廣告成效的因果量測，最後討論生成式 AI 對行銷與創新的影響。

每章採同一套結構：原始文本定位 → 關鍵名詞 → 核心論證 → 研究證據 → 誤讀邊界 → 跨章連結 → 練習。這不是逐字翻譯，而是以中文重建作者的問題、機制、證據與限制；為避免侵犯著作權，僅做摘要、釋義與必要的短語引用。

::: info 證據規則
理論模型不偽裝成已證明的普遍定律；觀察關聯不升格為因果；單一研究的效果量不直接外推；2025 年 GenAI 文章中的研究議程與管理者預期，會與既有實證分開標示。
:::

## 建議閱讀方式

- 第一輪：只讀每章的「一句話答案」「本章收束」與跨章連結。
- 第二輪：細讀機制表格、研究設計與誤讀邊界。
- 第三輪：回到原文指定段落，核對作者自己的論證與限制。
- 若要實作：先把練習題寫成自己的案例，再決定是否需要進一步閱讀統計或方法論原典。
