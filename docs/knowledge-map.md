|---|---|---|---|
| [1](/part-1/chapter-01) | [效果階層：廣告不是一次跳到購買](/part-1/chapter-01) | 第一部 | 未必。廣告可能先改變知曉、理解、喜好、偏好或確信；量測必須對準預期改變的層級。 |

| [3](/part-1/chapter-03) | [計畫行為理論：喜歡不等於會做](/part-1/chapter-03) | 第一部 | 行為不只取決於態度；主觀規範與知覺行為控制共同影響意圖，而實際控制條件會限制意圖能否轉成行為。 |
| [4](/part-1/chapter-04) | [展望理論：人不是用最終財富，而是用得失來感受風險](/part-1/chapter-04) | 第一部 | 在原始展望理論中，人先經過編輯階段，再以參考點把結果編碼成得失，並用價值函數與決策權重評估風險選項；損失側通常比同額獲得側更陡。 |
| [5](/part-1/chapter-05) | [社會影響：人為何順從、從眾與服從](/part-1/chapter-05) | 第一部 | 不同影響現象可由三個核心目標理解：看對世界、與人連結、維持正向且一致的自我。 |
| [6](/part-2/chapter-06) | [創新擴散：好產品不會自動擴散](/part-2/chapter-06) | 第二部 | 依讀本轉述的 Rogers 定義，擴散是創新經由特定渠道、隨時間在社會系統成員間被溝通的過程；採用不只由產品功能決定，也受創新的知覺屬性、溝通網絡與制度情境影響。 |
| [7](/part-2/chapter-07) | [持續注意力：吸引點擊與讓人讀下去是兩件事](/part-2/chapter-07) | 第二部 | 自然資料顯示易讀、句法較簡單、熟悉與具體的語言和持續內容消費相關；控制實驗則支持部分離散情緒透過喚起與不確定性影響持續注意，不能把所有語言特徵都解讀為已證實的因果效果。 |
| [8](/part-2/chapter-08) | [選擇架構：一個按鈕、順序與拆分方式如何改變採用](/part-2/chapter-08) | 第二部 | 可以。選項整合可減少多次決策造成的噪音；符合習慣的顏色可加快反應；像預設般的措辭也可提高啟用。但各機制不同，且透明度與自主性必須被保護。 |
| [9](/part-3/chapter-09) | [因果推論：先定義反事實，再選方法](/part-3/chapter-09) | 第三部 | 因果問題需要估計未被觀察到的反事實；高預測力只有在正確識別假設下，才可能協助因果推論。 |
| [10](/part-3/chapter-10) | [廣告報酬的「不利經濟學」：樣本很大，訊號仍可能太小](/part-3/chapter-10) | 第三部 | 因為可獲利的平均增量相對個人消費波動極小；要區分管理上接近的 ROI，需要極大樣本與事前規劃。提高處置強度可能改善訊號，但也會改變成本與目標 estimand，並非免費的精度工具。 |
| [11](/part-3/chapter-11) | [大數據不會自動消除偏誤：觀察法與廣告實驗的正面比較](/part-3/chapter-11) | 第三部 | 在本文的 15 個 Facebook 廣告實驗中，所研究的觀察方法多數高估 RCT 的 lift，但在部分案例顯著低估（p.219）。使用者活動內生性使曝光者本來就較可能轉換（p.197）；平台定向內生性一般造成向上偏誤，僅在特例可能反向（p.198）；競價內生性則視其他廣告主的出價與互補品而可能向上或向下（p.198）。 |
| [12](/part-4/chapter-12) | [生成式 AI 與創新流程：機會、研究問題與尚未證明的假設](/part-4/chapter-12) | 第四部 | 這篇文章把既有研究與管理者觀點整理成研究路線圖：特定構想與測試任務可能受益；AI 趨同、心理所有權下降與市場基礎資產改變則主要是待驗證的研究命題。 |
| [13](/part-4/chapter-13) | [生成式 AI 的導入治理：一般／客製輸入 × 低／高人工作業](/part-4/chapter-13) | 第四部 | 文章建議依輸入是否需要客製、任務風險、以及輸出與核心價值主張的關聯，配置不同程度的人類增強；2×2 是概念性決策起點，不是已由比較試驗證明的最佳配置。 |
