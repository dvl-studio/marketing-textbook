# 計畫行為理論：喜歡不等於會做

> 態度、主觀規範、控制感如何形成意圖，意圖又何時轉成行為

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Ajzen, I. (1991), “The Theory of Planned Behavior.” |
| <strong>文本性質</strong> | 理論綜述與經驗證據整理；回顧 TPB 的預測力與未解問題。 |
| <strong>本章核心問題</strong> | 為什麼一個人明明贊成、也說想做，最後仍沒有行動？ |
| <strong>一句話答案</strong> | 行為不只取決於態度；主觀規範與知覺行為控制共同影響意圖，而實際控制條件會限制意圖能否轉成行為。 |

:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>行為態度</strong> | Attitude toward the Behavior | 對「執行某個具體行為」的正負評價，而非對品牌或議題的一般喜好。 |
| <strong>主觀規範</strong> | Subjective Norm | 重要他人是否期待自己執行該行為的知覺壓力。 |
| <strong>知覺行為控制</strong> | Perceived Behavioral Control | 個人對執行特定行為之容易或困難程度的知覺；它反映控制信念與各促進／阻礙因素的知覺力量，不等同客觀控制。 |
| <strong>行為意圖</strong> | Behavioral Intention | 願意投入多少努力、打算多強烈地執行行為。 |
| <strong>相容原則</strong> | Compatibility Principle | 態度、意圖、控制與行為的行動、對象、情境、時間必須對齊。 |

## 1. 一張圖理解 TPB

TPB 先解釋意圖，再解釋行為：行為態度、主觀規範與知覺行為控制共同預測意圖；意圖與知覺行為控制再共同預測行為。知覺控制只有在能合理反映實際控制時，才可能在意圖之外提供額外的行為預測資訊。

| 前因 | 核心問題 | 對意圖的可能作用 | 介入方向 |
|---|---|---|---|
| <strong>態度</strong> | 做這件事是好是壞？ | 預期結果越有價值，意圖通常越強 | 改變結果信念與結果評價 |
| <strong>主觀規範</strong> | 重要的人認為我該做嗎？ | 知覺社會壓力可提高或降低意圖 | 改變規範信念與參照者訊息 |
| <strong>控制感</strong> | 我做得到嗎？ | 控制感可提高意圖，也可協助預測行為 | 增加技能、時間、機會與可行性 |
| <strong>意圖</strong> | 我有多認真打算做？ | 在自願控制高時，是較近端預測者 | 形成具體承諾與執行安排 |

## 2. 一般態度為何常預測不了特定行為

「我支持環保」與「我本週會搭乘大眾運輸三次」不是同一層級。一般態度可能與一組長期行為相關，卻難以預測某一次、某情境的具體行動。若研究問題是具體行為，量測也必須具體到行動、對象、情境與時間。

這個原則解釋許多看似「態度沒有用」的結果：問題不一定是理論失敗，而可能是把寬泛態度拿去預測窄小行為。反過來，過度具體的意圖也不能直接代表長期人格。

## 3. 意圖—行為落差：不是所有問題都叫動機不足

當行為高度可控，例如在兩個現成選項中選一個，意圖常較能預測行為；當行為需要時間、金錢、技能、他人合作或外部機會，控制變得重要。兩個人都想學會滑雪，但有教練、設備與時間的人更可能成功。

知覺控制不等於真實控制。若人對難度過度樂觀，問卷中的控制感可能預測不佳；若情境突然改變，先前意圖也會失效。因此 TPB 不是只做一次態度調查，而是要求量測與實際執行條件相連。

::: tip 診斷意圖—行為落差
先分四類：意圖其實不強；意圖不穩定；控制感不準確；真實資源／機會不足。四類問題需要四種不同介入。
:::

## 4. 從信念層找到可以改變的槓桿

態度、規範與控制感不是終點。Ajzen 進一步把它們連回行為信念、規範信念與控制信念：人預期哪些結果及如何評價結果、重要參照者怎麼想及自己是否願意順從、哪些因素會幫助或阻礙及其力量多大。可設計的介入通常落在這些具體信念與實際環境條件。

原文指出：信念基礎測量與整體測量之間經常只出現中等大小的相關；期望—價值模型獲得一定支持，但確切形式仍不確定，且重新調整量尺所帶來的相關提升仍不足以解決此問題。依原文，TPB 原則上開放納入額外預測變項，條件是它們在現有變項之外仍能解釋意圖或行為的顯著變異。例如：在三種不道德行為的意圖上，加入道德義務使解釋變異再增加 3–6%，且皆顯著（p.200）；過去行為在除偷竊外的研究中仍有顯著殘餘效果，多數殘餘效果小到可能來自方法變異，但求職研究的複相關由 .42 升至 .71，不像方法變異（pp.203–204）。作者認為僅憑這些有限研究下結論仍屬過早，意圖與知覺控制是否足以解釋行為的大部分系統變異，有待進一步研究。

## 研究證據怎麼讀

- 原文整理多種行為研究；意圖與知覺控制對行為的複相關約介於 .20–.78，平均約 .51。 最弱的預測出現在減重與取得課程 A：作者推測這兩類行為最難以意志控制，知覺控制與實際控制也最可能不一致（旁證：學業研究中 PBC 的預測力隨學期進展而提高）。多數研究中意圖比 PBC 更重要，僅減重研究是 PBC 壓過意圖。
- 態度、主觀規範與控制感對意圖的複相關約介於 .43–.94，平均約 .71；不同構念的重要性會隨行為與情境改變。 在 Table 2 的各項研究中，知覺行為控制的係數每項都顯著，態度除一例外也顯著；主觀規範的結果則不一、沒有明顯規律，作者認為就所考察的行為而言，個人考量往往壓過社會壓力。
- 這些相關不是固定效果，也不代表每一條路徑都是因果；研究品質、測量相容性與控制真實性都會影響結果。

## 不要這樣誤讀

::: danger 常見誤讀
「只要提升態度就會提升行為。」TPB 明確把規範與控制納入，行為還受真實機會限制。
:::

::: danger 常見誤讀
「知覺控制就是自信。」它針對特定行為的可行性，可能含技能與外部障礙；不能與一般人格自信混為一談。
:::

## 本章收束

- 預測具體行為，就要使用具體、相容的量測。
- 意圖重要，但資源、機會與控制決定是否落地。
- 介入前先判斷問題在態度、規範、控制，還是意圖之後的執行條件。
