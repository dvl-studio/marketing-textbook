# 社會影響：人為何順從、從眾與服從

> 準確、歸屬與正向自我概念，是許多影響技巧背後的共同動機

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Cialdini, R. B., &amp; Goldstein, N. J. (2004), “Social Influence: Compliance and Conformity.” |
| <strong>文本性質</strong> | Annual Review 綜述；以 1997–2002 年的順從與從眾研究為主，服從作為相鄰概念而非全文的第三個對等主題。 |
| <strong>本章核心問題</strong> | 為什麼我們有時跟隨多數，有時聽從權威，有時為了維持自我一致而答應請求？ |
| <strong>一句話答案</strong> | 不同影響現象可由三個核心目標理解：看對世界、與人連結、維持正向且一致的自我。 |

::: info 本章讀完後，你應該能夠
區分 compliance 與 conformity，並理解它們和 obedience 的概念邊界；用三目標架構理解研究結果；辨識描述性與命令性規範；看見影響的自動性與倫理風險。
:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>順從</strong> | Compliance | 在他人請求下改變行為，未必改變私下信念。 |
| <strong>從眾</strong> | Conformity | 使自己的行為或判斷與他人反應一致。 |
| <strong>服從</strong> | Obedience | 依原文，區分單純順從與服從的關鍵在權威的基礎——專業型權威 vs. 以階層位置為基礎的合法權力。 |
| <strong>描述性規範</strong> | Descriptive Norm | 人們實際上通常怎麼做。 |
| <strong>命令性規範</strong> | Injunctive Norm | 群體通常認可或反對什麼。 |

## 1. 三個核心目標

| 目標 | 內在問題 | 常見影響來源 | 風險（教材補充） |
|---|---|---|---|
| <strong>準確 Accuracy</strong> | 什麼才是真的／有效？ | 多數資訊、專家、社會證明 | 把共識誤認為事實 |
| <strong>歸屬 Affiliation</strong> | 我是否被接納與喜歡？ | 相似性、互惠、群體規範 | 壓抑異議、排除外群體 |
| <strong>正向自我 Self-concept</strong> | 我是否一致、善良、有能力？ | 承諾、登門檻、公開立場 | 被利用一致性壓力 |

## 2. 順從技巧不是魔法按鈕

登門檻技術先取得小承諾，再提出較大請求；拒絕後退讓先提出較大請求，再退到目標請求；low-ball 則是在對方形成初步承諾後，改變或補充使交易較不利的條件。各技巧涉及的機制並不相同，效果也不保證能跨請求類型、關係與文化情境複製。

（1）拒絕後退讓（DITF）：互惠讓步解釋長期受質疑；後設分析顯示讓步幅度不是顯著預測因子，支持者回應：只要對方把退讓視為真誠讓步，就會越過門檻（pp.600–601）。（2）登門檻（FITD）：自我知覺是否為中介仍有爭議——Gorassini &amp; Olson（1995）以私下順從為依變項，發現自覺助人性提高並未帶來更高順從；Burger &amp; Caldwell（2003）則發現順從受自評助人量表的一個向度中介（pp.603–604）；Cialdini 等（1995）發現只有「一致性偏好」高者才依一致性理論順從，Guadagno 等（2001）發現低 PFC 者被提醒其助人行為時順從反而降低（p.603）。（3）同一人幾乎無延遲地連續提出兩個請求，可能引發反彈（p.604）。（4）順從研究以北美樣本為主；一致性需求在美國高於波蘭，且差異主要來自個人的個人主義—集體主義取向（pp.605–606）。

綜述也強調抗拒力量。原文指出：若同一人在幾乎沒有延遲下連續提出兩個請求，目標對象可能因互惠規範而產生抗拒（boomerang；p.604）。真正的理論問題不是「技巧是否有效」，而是它在何種目標、知覺與情境下有效。

## 3. 從眾：資訊與規範常同時作用

依原文，資訊性從眾來自形成準確解讀的動機，規範性從眾來自獲得他人認可的動機；兩者概念上獨立，但經驗上常相互關聯、難以分離（p.606）。原文另指出，當個人須向觀點已知的他人負責時，多數人會迎合對方；只有同時被啟動準確動機且須負責者，才較能抗拒已知但有缺陷的群體共識（Quinn &amp; Schlenker, 2002；pp.606–607）。

描述性規範與命令性規範必須一致。（教材例示）若訊息一面說「請勿浪費」，一面暗示「很多人都在浪費」，描述性訊號可能抵銷道德呼籲。原文指出，規範只有在居於意識焦點時才會指引行為（Kallgren 等，2000），且描述性與命令性規範是否一致也會改變效果；公共服務訊息的長期效果可能因規範資訊隨時間變得不易取得而受損，將命令性規範訊息連結到功能性提示可提高日後的規範可近性（pp.597–598）。

從眾研究也包括：動力系統社會影響理論（本地多數更具影響、少數群集不易消失；p.608）、行為模仿（受試者無意識地模仿同伴，被模仿者更喜歡模仿者；pp.609–610），以及文化差異（不從眾在東亞被視為偏差、在西方被視為獨特；p.610）。

原文指出，把 Milgram 的服從研究類比為大屠殺中的加害者行為受到批評（Milgram 的實驗者同時具合法與專業權威，且受試者情感上反對命令）；同時採實驗設計與行為依變項的服從研究很少，因為倫理限制（pp.596–597）。

::: tip 規範訊息檢查
先問你在傳達「大家怎麼做」還是「大家認為應該怎麼做」；若兩者衝突，受眾可能選擇最容易合理化的那一個。
:::

## 4. 影響往往發生在意識之外

2004 年綜述的重要趨勢，是把焦點從明顯壓力轉向微妙、間接、啟發式甚至未被察覺的影響。熟悉、相似、短暫對話、情緒變化與選項重述，都可能改變反應。

這也提高倫理要求：若受眾無法辨識自己正在被影響，設計者應更重視自主性、可退出性與後果，而不能只用轉換率證明正當性。

## 研究證據怎麼讀

- 這篇是文獻綜述，不是單一實驗；它主要整合順從與從眾研究，並在討論社會影響時連結權威、自動性與相關現象。
- 作者把現象歸入三個主要目標，但明確指出同一行為可能同時服務多個目標。
- 研究多來自北美情境，作者也提醒文化差異與外推限制。

## 不要這樣誤讀

::: danger 常見誤讀
「規範只要存在就會發揮作用」是常見誤讀。原文指出，規範只有在居於焦點時才指引行為，描述性與命令性規範是否一致也會改變效果（p.597）。
:::

::: danger 常見誤讀
「一致性代表人被操控。」一致性也能支持可靠承諾；倫理問題在資訊透明、自由選擇與利益是否對稱。
:::

## 本章收束

- 先判斷影響行為服務哪一個心理目標。
- 規範訊息要區分「實際行為」與「社會認可」。
- 有效不等於正當；影響技巧越不易察覺，治理責任越高。

## 思考與練習

1. 找一個你最近從眾的例子，判斷主要是資訊性還是規範性。
2. 把一則「很多人都違規」的提醒改寫成不強化負面描述性規範的版本。
3. 比較登門檻與拒絕後退讓：兩者各自依賴哪些心理目標？

> <strong>原文回讀建議｜</strong>先讀摘要、Compliance 與 Conformity 的三目標架構，再讀 Conclusion；技巧細節可按需求選讀。
