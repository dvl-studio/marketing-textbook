# 展望理論：人不是用最終財富，而是用得失來感受風險

> 參考點、損失側較陡、機率加權與表述敏感性的原始結構

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Kahneman, D., &amp; Tversky, A. (1979), “Prospect Theory: An Analysis of Decision under Risk.” |
| <strong>文本性質</strong> | 理論論文與選擇問題證據；提出期望效用理論的描述性替代模型。 |
| <strong>本章核心問題</strong> | 為什麼人會同時買保險與彩券，也會因同一結果的表述方式改變選擇？ |
| <strong>一句話答案</strong> | 在原始展望理論中，人先經過編輯階段，再以參考點把結果編碼成得失，並用價值函數與決策權重評估風險選項；損失側通常比同額獲得側更陡。 |

::: info 本章讀完後，你應該能夠
區分規範模型與描述模型；解釋參考點與損失側較陡；理解確定性、反射與隔離效應；區分 1979 原文與後來的「損失趨避／框架效應」術語。
:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>參考點</strong> | Reference Point | 把結果判定為獲得或損失的心理基準。 |
| <strong>價值函數</strong> | Value Function | 對參考點變化的主觀價值；獲得區通常凹、損失區通常凸，損失側更陡。 |
| <strong>決策權重</strong> | Decision Weight | 人對機率的心理權重，不等同客觀機率本身。 |
| <strong>確定性效應</strong> | Certainty Effect | 相較於只是「很可能」，確定結果被賦予額外吸引力。 |
| <strong>隔離效應</strong> | Isolation Effect | 比較時忽略選項共同部分，導致等價問題因拆解方式不同而選擇不同。 |

## 1. 期望效用為何不夠描述真實選擇

期望效用理論可作為風險選擇的一項規範基準；Kahneman 與 Tversky 透過一系列假設選擇題，展示確定性、反射與隔離等穩定模式，並據此質疑期望效用作為描述模型的充分性。這些題目顯示的是系統性模式，不代表所有人、所有情境都必然違反同一公理。

展望理論因此不是宣布理性無用，而是提供一個描述模型：人在面對風險時，會先編輯問題，再評估被編輯後的選項。

## 2. 先編輯，再評估

| 編輯操作 | 人在做什麼 | 可能造成的結果 |
|---|---|---|
| <strong>編碼 Coding</strong> | 相對參考點標成獲得或損失 | 同一結果因基準不同而感受不同 |
| <strong>組合 Combination</strong> | 合併相同結果的機率 | 簡化複雜選項 |
| <strong>分離 Segregation</strong> | 把確定部分與風險部分拆開 | 確定成分變得突出 |
| <strong>抵銷 Cancellation</strong> | 刪除選項共同成分 | 隔離效應與對表述方式的敏感 |
| <strong>簡化 Simplification</strong> | 四捨五入或忽略極小差異 | 可能改變支配關係的知覺 |
| <strong>支配偵測 Detection of dominance</strong> | 掃描選項，找出被支配者並直接剔除，不再進一步評估 | 降低評估負擔 |

作者承認某些編輯操作會允許或阻止其他操作，最終編輯結果可能取決於操作順序與呈現格式；本文只處理編輯結果可以無歧義界定的選擇問題。

## 3. 價值函數：得失而非最終資產

原始模型假設價值函數在獲得區通常凹、在損失區通常凸，因此在論文所討論的純風險選擇中，常分別對應風險趨避與風險尋求；這不是跨所有混合選項與情境的無條件定律。損失側通常更陡，表示相對同一參考點的同額損失往往比同額獲得影響更大。

原始論文以資產位置與問題表述說明參考點，也承認參考點可能受期待影響；本文未使用「loss aversion」或「framing effect」兩個詞，而以「losses loom larger than gains」及對 prospects formulation／表述的敏感呈現相近概念。（以下為本書依後續文獻的補充，非 1979 年原文內容）承諾價格、所有權等來源由後續研究擴充。改變表述可能改變編碼方式，但不能據此推論參考點可被任意操控。

::: tip 簡化圖像
獲得區：邊際感受遞減；損失區：對小幅損失特別敏感；跨越參考點：心理斜率突然改變。
:::

## 4. 機率不是照原比例進入心理

原始理論以決策權重處理客觀機率；決策權重不是主觀機率，通常也不具可加性。 決策權重一般低於對應機率，唯低機率範圍例外（被高估）；對小機率，權重函數呈次可加，但在大機率範圍不一定成立。極低機率在編輯階段可能被忽略，保留下來的小機率則可能得到相對較大的權重；確定結果又可能獲得額外權重。原文主張：對低機率的高估「可能有助於」解釋保險與賭博同時具有吸引力（例如 Problem 14 偏好彩券式選項、14′ 把小額損失視為保費）；它並未宣稱此機制已完整解釋保險購買，並指出人們對機率保險的普遍排斥與「效用函數處處為凹」的說法不相容。

但不要把「小機率一定被高估」當成無條件定律。極低機率也可能在編輯時被忽略；風險是否突出、是否容易想像、問題如何呈現都會影響權重。

## 研究證據怎麼讀

- 論文以受試者在成對風險選擇中的一致模式為主要證據，並提出價值函數與權重函數的形式化模型。 證據主要來自學生與教職員對假設性（非真實金錢）選擇題的回答，題目金額以以色列貨幣表示，並在 Stockholm、Michigan 樣本得到基本相同的模式；作者承認依賴假設選擇有其疑慮。理論本身是為金額結果與明示機率的簡單展望而建立，之後才延伸到更複雜的選擇。
- 確定性效應、反射效應與隔離效應共同說明：同一客觀期望值不會保證同一心理評價。
- 1979 年版本是原始展望理論；後續累積展望理論對多結果排序與權重處理有重要修正，本章不將兩者混稱。

## 不要這樣誤讀

::: danger 常見誤讀
「損失一定是獲得的兩倍。」原文提出損失側更陡，但不存在跨情境固定的通用倍數。
:::

::: danger 常見誤讀
「框架可以讓人做任何事。」原文只顯示選擇會受 prospects 的 formulation／表述影響；「框架效應」是後來常用術語，且不能取代利益、信任、經驗與制度約束。
:::

## 本章收束

- 先找參考點，再談獲得與損失。
- 客觀機率與心理權重不可直接畫等號。
- 展望理論是描述性工具，不是操控清單，也不是所有決策偏誤的總稱。

## 思考與練習

1. 同一個 500 元優惠，分別用「得到」與「避免失去」表述；兩者的參考點是什麼？
2. 找一個保險或保固選擇，分析低機率與損失側如何共同作用。
3. 設計一個不涉及欺騙、但可以檢驗不同表述是否改變選擇（後來常稱框架效應）的小實驗。
