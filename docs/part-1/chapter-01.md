# 效果階層：廣告不是一次跳到購買

> 從認知、情感到行動，先問訊息要推動哪一個心理步驟

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Lavidge, R. J., &amp; Steiner, G. A. (1961), “A Model for Predictive Measurements of Advertising Effectiveness.” |
| <strong>文本性質</strong> | 概念模型／理論性文章；提出效果階層與量測邏輯，並非單一因果實驗。 |
| <strong>本章核心問題</strong> | 如果廣告沒有立刻帶來銷售，是否代表它沒有作用？ |
| <strong>一句話答案</strong> | 未必。廣告可能先改變知曉、理解、喜好、偏好或確信；量測必須對準預期改變的層級。 |

::: info 本章讀完後，你應該能夠
說明為什麼銷售不是所有廣告唯一且即時的指標；區分認知、情感與行動三類效果；把溝通目標改寫成可觀察的中介結果；辨識線性漏斗模型的限制。
:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>效果階層</strong> | Hierarchy of Effects | 消費者從不知道到採取行動的多階段變化。 |
| <strong>認知</strong> | Cognitive | 知曉、辨認、理解與記憶等「知道什麼」。 |
| <strong>情感</strong> | Affective | 喜好、態度、偏好等「感覺如何」。 |
| <strong>意動／行動傾向</strong> | Conative | 確信、意圖與行動準備等「是否要做」。 |
| <strong>中介結果</strong> | Intermediate Outcome | 在最終購買之前，可被觀察且理論上應先改變的結果。 |

原文稱「階梯式模型（stair-step model）」，七個位置為：未知曉→知曉→知識→喜好→偏好→確信→購買。「效果階層（Hierarchy of Effects）」是後續文獻對此類模型的通稱，「中介結果」為本書教學用語，兩者皆非原文用語。

## 1. 模型為何出現：長期效果也必須留下短期軌跡

Lavidge 與 Steiner 的出發點很直接：廣告的終極商業功能固然與銷售有關，但多數人不會在看到訊息後立即從「毫無興趣」跳到「完成購買」。如果決策涉及金額、風險、比較或他人意見，中間通常存在多個心理門檻。

因此，所謂「長期效果」不能成為不量測的藉口。若廣告真的在長期產生影響，短期應該觀察到某些前置狀態改變，例如更多人知道品牌、理解產品差異、形成偏好或產生購買意圖。這些中介結果不是銷售的替代品，而是用來檢查理論鏈條是否正在發生。

## 2. 七個位置、六個推進階段與三種心理功能

原文先列出從「完全未知曉」到「購買」的七個位置；但在對應三種廣告心理功能時，明確從「知曉」起算六個推進階段。完全未知曉是階梯的起點／基準狀態，不屬於這六個功能步驟。這張階梯是診斷圖，不是自然定律：不同位置需要不同訊息，也應使用不同量測工具。

| 階段 | 主要問題 | 心理功能 | 可能量測 |
|---|---|---|---|
| <strong>未知曉</strong> | 他知道這個選項存在嗎？ | 起點／基準狀態 | 無提示知曉、提示知曉（教材延伸） |
| <strong>知曉</strong> | 他能辨認名稱或線索嗎？ | 認知 | 品牌知曉調查、輔助回想 |
| <strong>理解／知識</strong> | 他知道能解決什麼問題嗎？ | 認知 | 資訊型問題、回放分析 |
| <strong>喜好</strong> | 他對此是否有正向感受？ | 情感 | 態度量表、語意差異、形容詞檢核表 |
| <strong>偏好</strong> | 與替代方案相比是否更想選它？ | 情感 | 品牌偏好排序 |
| <strong>確信（conviction）</strong> | 他是否相信選擇合理並準備行動？ | 意動 | 購買意圖 |
| <strong>購買</strong> | 是否真的完成行為？ | 意動（行動） | 市場／銷售測試、重複購買 |

## 3. 正確用法：先定義要移動哪一格

這個模型最有價值的地方，不是把所有人塞進同一條漏斗，而是迫使研究者先說清楚「這一次介入預期改變什麼」。新產品上市初期可能重視知曉與理解；高度熟悉的品類，問題可能在偏好或行動摩擦。若目標不同，素材、時窗與成功標準也不同。

量測也應同時保留「整體位置」與「構成因素」。例如整體品牌偏好提高，可能來自可靠感、易用性或價格印象的變化。只看總分會錯過機制；只看單一形象詞又可能失去商業意義。

原文以「假設」形式提出：購買所涉的心理或經濟承諾越高，消費者越需要較長時間攀升各階，個別階段也越重要；承諾越低，越可能近乎立即跳到頂端（衝動購買可能完全沒有事前知曉）。不同產品或廣告可鎖定不同階段：「Buy Now」廣告針對最後一階；工業廣告多半為業務員鋪路，著重知曉、知識與好感；新車廣告在新車款上市時偏重低階，年度尾聲轉向促成購買。以上為作者的假設與例示，並非實證結果。

::: tip 判讀順序
先寫最終行為 → 找必要的前置門檻 → 選擇最接近本次介入的主要結果 → 同時保留更下游的驗證指標。
:::

## 4. 一個完整例子：安全感不是購買本身

本節為教材自編示例，非原文內容。

假設一項數位服務要提高首次使用。若研究顯示使用者甚至不知道服務能做什麼，第一輪訊息的主要結果可以是正確理解率；若大多數人已理解但不信任，主要結果應改為風險認知、信任或啟用意圖；若意圖高但完成率低，問題可能已不在廣告，而在流程、資格或技術。

同一個「轉換低」表象，可能對應完全不同的介入。效果階層提供的是問題定位，而不是保證只要上層提高，下層就必然等比例上升。

## 研究證據怎麼讀

- 這篇文章以概念建構和研究設計建議為主，沒有提供單一樣本可直接估算各階段的固定轉換率。
- 七個位置是理想化的診斷架構；其中三種心理功能對應的是從知曉到購買的六個推進階段。實際決策可能跳躍、往返、同時發生，或受情境中斷。
- 原文把「階梯上移動較多者，是否最終以較高比例或數量購買」列為檢驗模型假設的方法（Testing the Model）；該文為概念模型，並未提供此檢驗的實證結果。

## 不要這樣誤讀

::: danger 常見誤讀
「每位消費者一定依序走完七步。」原文承認簡單模型假設大家從零開始，但有些人已有負面態度，比完全未知曉者離購買更遠；第一個任務是先讓他們離開負面階梯，才能再往上走。
:::

::: danger 常見誤讀
「提高知曉就等於提高銷售。」提高知曉不等於提高銷售：知曉不是充分條件；原文還指出，衝動購買可在沒有事前知曉、知識、喜好或確信的情況下發生，因此對低承諾購買而言，知曉甚至未必是必要條件。
:::

## 本章收束

- 先確定介入要改變哪個門檻，再選指標。
- 中介結果能檢查機制，但不能單獨證明最終商業效果。
- 漏斗不是人性的固定流程，而是將模糊目標拆成可診斷問題的工具。

## 思考與練習

1. 選一個你最近採用的新服務，回想你是否真的依序經過七階段；哪些階段被跳過？
2. 把「提升品牌」改寫成一個清楚的中介結果與一個下游驗證結果。
3. 如果知曉提高、偏好不變、購買下降，你會提出哪三個不同解釋？
