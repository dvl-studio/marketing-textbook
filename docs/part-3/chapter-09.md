# 因果推論：先定義反事實，再選方法

> 預測「會發生什麼」與估計「改變 X 會造成什麼」是不同任務

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Varian, H. R. (2016), “Causal Inference in Economics and Marketing.” |
| <strong>文本性質</strong> | 入門方法論文章；面向熟悉機器學習的讀者，介紹反事實與經濟學識別方法。 |
| <strong>本章核心問題</strong> | 有一個高度準確的預測模型，為什麼仍不能回答介入效果？ |
| <strong>一句話答案</strong> | 因果問題需要估計未被觀察到的反事實；高預測力只有在正確識別假設下，才可能協助因果推論。 |

::: info 本章讀完後，你應該能夠
區分預測與因果；說明反事實與選擇偏誤；比較 RCT、自然實驗、IV、RDD、DiD；理解機器學習在因果中的角色。
:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>反事實</strong> | Counterfactual | 同一單位在另一處置狀態下本來會出現的潛在結果；對已接受處置者，未處置結果是反事實，反之亦然。 |
| <strong>處置效果</strong> | Treatment Effect | 同一單位兩個潛在結果之差；個體效果通常無法同時觀察，研究多以平均處置效果等可識別 estimand 為目標。 |
| <strong>選擇偏誤</strong> | Selection Bias | 接受處置者與未接受者原本就不同，造成表面差異。 |
| <strong>識別</strong> | Identification | 用設計與假設把觀察分布連到因果量。 |
| <strong>處置後變項</strong> | Post-treatment Variable | 可能被處置改變的變項；不宜隨意放入控制模型。 |

## 1. 相關為何會騙人

假設衝浪電影在 Honolulu 同時有較高廣告支出與票房。簡單回歸可能把當地對衝浪的既有興趣算成廣告效果。問題不是「回歸不夠複雜」，而是廣告支出與未觀察需求由同一原因共同決定。

因果問題問的是：若我們介入並改變廣告支出，結果會如何？這與用歷史配置規則預測銷售不同，因為介入本身改變了資料生成過程。

## 2. 方法不是清單，而是反事實來源

| 方法 | 反事實從哪裡來 | 核心假設 | 典型限制 |
|---|---|---|---|
| <strong>RCT</strong> | 隨機分配的控制組 | 分配正確、干擾可控 | 成本、污染、外部效度 |
| <strong>自然實驗／IV</strong> | 影響處置但不直接影響結果的外生變動 | 相關性、排除限制與工具外生性；若解釋 LATE，通常還需單調性 | 工具弱、效果族群特定 |
| <strong>迴歸不連續 RDD</strong> | 門檻兩側非常接近的單位 | 門檻附近不可精準操控 | 只識別門檻附近效果 |
| <strong>差異中的差異 DiD</strong> | 對照組提供共同趨勢 | 未處置潛在結果具平行趨勢、無預期反應，且無差異性同步衝擊 | 趨勢違反與組成改變 |
| <strong>時間序列反事實／TTTC</strong> | 處置前資料建立可驗證預測 | 穩定關係、無處置污染預測因子 | 模型外推與結構變化 |

「核心假設」欄中的 LATE／單調性、無預期反應、無差異性同步衝擊、estimand 等為教材補充（標準計量文獻）；Varian 原文僅陳述：IV＝工具影響 x 且與 e 無關；DiD＝處置組若未被處置，其變化會與對照組相同；RDD＝門檻兩側個體近似可比。

::: tip Varian 的例子
Super Bowl 自然實驗（主場城市收視約高 10–15%，廣告早於球隊確定而購買）→ IV 的工具；以色列班級人數（40 vs 41 人）與最低飲酒年齡（21 歲）→ RDD；對門檻規則加入小隨機數（score + ε）可低成本地顯式隨機化。
:::

## 3. Train–Test–Treat–Compare

Varian 提出 Train–Test–Treat–Compare：用處置前資料訓練模型，在未處置測試期驗證預測，介入後預測未處置反事實，再與實際結果比較。Varian 指出 TTTC 與 Abadie 等人的合成控制法相似（合成控制以其他個體結果的凸組合建構預測，但原則上可用其他模型預測反事實），並將 TTTC 視為傳統處置—控制設計的推廣；它估計的是對被處置者（此廣告主）的處置效果。

關鍵不是模型多先進，而是處置前是否真的能預測、處置是否影響了模型輸入、處置期是否出現其他結構變化。Varian 提醒：建構反事實預測模型時，不要使用可能受處置影響的預測變數，否則會產生混淆問題；相對地，像「假期」這類同時影響廣告支出與銷售的混淆因子，應納入模型作為額外預測變數。（「處置後變項」「把效果控制掉」是本書的教學說法。）

::: tip 因果工作順序
先寫 estimand（要估哪一群、哪種介入、哪個時窗的效果）→ 找反事實來源 → 列識別假設 → 再談演算法與估計。
:::

## 4. 機器學習能做什麼、不能做什麼

機器學習可能改善反事實的預測（例如以交叉驗證調校模型、以隨機森林預測反事實），也可用於建立「誰接受處置」的預測模型；但它無法單靠擬合準確度創造外生變異。它可以讓你更準確地描述「像誰會被投放」，卻不能自動保證在條件化後已無未觀察混淆。

因果推論的核心是設計與可辯護假設；演算法是估計工具。若識別錯誤，模型越精準，可能只是越精準地重現偏誤。

## 研究證據怎麼讀

- 本文是方法入門與案例說明，不是比較所有方法效能的系統性實證。
- 文章把 RCT 視為黃金標準，但也說明在不可實驗時如何利用自然變異與預測反事實。
- TTTC 需要處置前測試期驗證，且不能使用被處置影響的預測變項。

## 不要這樣誤讀

::: danger 常見誤讀
「只要控制很多變項就是因果。」控制項若遺漏混淆、測量錯誤或受處置影響，結論仍可能偏誤。
:::

::: danger 常見誤讀
「機器學習準確度高，所以因果效果可信。」預測準確與因果識別是不同層次。
:::

## 本章收束

- 所有因果問題都先從反事實開始。
- 方法名稱不重要，重要的是反事實來源與識別假設。
- 機器學習可改善估計，不能取代研究設計。

## 思考與練習

1. 把「看過廣告的人買更多」拆成三個可能的非因果解釋。
2. 為一項政策選 RCT、RDD 或 DiD，並明確寫出核心假設。
3. 找一個可能的處置後變項，說明把它控制進回歸會造成什麼問題。

> <strong>原文回讀建議｜</strong>先讀 motivating problem 與 basic identity，再讀 controlled experiments、TTTC、RDD、IV、DiD；每節都問反事實從哪裡來。
