# 持續注意力：吸引點擊與讓人讀下去是兩件事

> 易處理語言、情緒喚起與不確定性如何影響內容消費

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Berger, J., Moe, W. W., &amp; Schweidel, D. A. (2023), “What Holds Attention? Linguistic Drivers of Engagement.” |
| <strong>文本性質</strong> | 多方法研究；大型自然閱讀資料＋控制實驗。 |
| <strong>本章核心問題</strong> | 什麼語言能讓人不只點進來，而是繼續讀下去？ |
| <strong>一句話答案</strong> | 自然資料顯示易讀、句法較簡單、熟悉與具體的語言和持續內容消費相關；控制實驗則支持部分離散情緒透過喚起與不確定性影響持續注意，不能把所有語言特徵都解讀為已證實的因果效果。 |

區分吸引注意與維持注意；理解處理流暢性四個面向；解釋喚起與不確定性的情緒機制；辨識注意力最佳化的品牌與社會風險。

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>持續注意</strong> | Sustained Attention | 內容開始後，受眾仍持續消費而非離開。 |
| <strong>處理流暢性</strong> | Processing Ease | 文字被解碼、解析與理解的容易程度；本章以可讀性、句法簡單、熟悉性與具體性等可觀察語言特徵近似衡量，而非把它們視為完全相同的心理構念。 |
| <strong>具體性</strong> | Concreteness | 詞彙是否容易連到可感知的對象或經驗。 |
| <strong>喚起</strong> | Arousal | 情緒使人警覺、活化與注意的程度。 |
| <strong>不確定性</strong> | Uncertainty | 人對接下來會發生什麼仍有待解答的程度。 |

## 1. 指標不同，結論就可能不同

點擊、按讚、分享與持續內容消費常被統稱為 engagement，但它們不是同一行為。吸引進站不等於讓人繼續閱讀；本研究把內容開始後是否持續消費獨立操作化，因此不能把其結果直接換算成理解、記憶或閱讀完成率。

這個區分具有方法意義：若成功指標是滑動深度或段落完成率，內容特徵的效果可能與點擊率相反。

## 2. 什麼文字更容易被讀下去

| 文字特徵 | 預期機制 | 例子 | 注意事項 |
|---|---|---|---|
| <strong>可讀性</strong> | 縮短解碼時間 | 短詞、較短句 | 不可犧牲精確度 |
| <strong>句法簡單</strong> | 降低解析負荷 | 主幹清楚、少巢狀結構 | 專業內容仍需必要複雜度 |
| <strong>熟悉性</strong> | 降低詞彙搜尋成本 | 常用同義詞 | 熟悉不等於陳腔濫調 |
| <strong>具體性</strong> | 形成較清楚的心理表徵 | 「紅色手機」而非「產品」 | 抽象概念需配例子 |

## 3. 情緒不是只有正面／負面

Study 1（自然資料）只測量憤怒、焦慮與悲傷：焦慮語言最能維持閱讀（β = .042），憤怒較弱（β = .011），悲傷則降低持續閱讀（β = −.036）（p.800）。Study 2（N = 278，MTurk）操弄文章中的悲傷／焦慮／憤怒語言：選擇繼續閱讀的比例為悲傷 52%、焦慮 80%、憤怒 71%（p.802）。「興奮」與「希望」來自 Study 3（N = 248，Prolific，預先註冊）：受試者先回憶並書寫自己感到滿足、興奮或希望的經驗（偶發情緒操弄），再閱讀一則中性文章並報告繼續閱讀的意願，比較基準是「滿足」（pp.803–804）。因此興奮與希望的結果是情緒狀態操弄，而不是文本語言的操弄。這些結果是特定內容、操作化與平台下的平均效果，不能直接推成所有情緒文本的固定排序。

憤怒屬高喚起但確定性也高，效果因此可能介於兩者。 Study 2 中，憤怒組繼續閱讀的比例（71%）介於焦慮（80%）與悲傷（52%）之間。中介分析顯示：相較悲傷，憤怒語言的效果只經由喚起（ab = .44，95% CI \[.20, .82\]），不確定性的間接效果未達顯著（ab = −.06，CI \[−.26, .03\]）；焦慮相對憤怒的差異則經由不確定性（ab = .18，CI \[.009, .51\]），喚起的間接效果未達顯著（ab = −.24，CI \[−.58, .04\]）。這提醒內容設計不能只建立「正向詞／負向詞」字典，而要對離散情緒與任務情境做更細判斷。

::: tip 寫作轉換
抽象句：「本方案改善使用者體驗。」具體句：「使用者能在同一頁看到總價、到貨日與退貨方式。」後者不一定更華麗，但更容易形成可理解的心理表徵。
:::

## 4. 大型資料與實驗各自回答什麼

研究第一部分分析 649,129 次內容消費事件與 35,448 篇內容，運用可觀察控制項與模型規格檢驗語言特徵，但仍屬自然資料的關聯證據。 資料為九個網站、兩週的隨機樣本，僅含至少有兩次互動的頁面讀取；依變項是「是否繼續讀下一段」。作者承認即使有控制變項與穩健性檢查，選擇偏誤仍可能是疑慮（p.801）。效果量方面，可讀性提高一個標準差，完成整篇的可能性約提高 25%，焦慮語言約提高 14%（p.801）。後續控制實驗中，Study 2 操弄文章中的情緒語言；Study 3 則先以回憶書寫偶發操弄情緒狀態，再讓各組閱讀相同的中性文章。兩者為情緒效果及喚起、不確定性機制提供較強的因果支持；自然資料與實驗的證據層級不可混稱。

多方法設計的優點是把真實行為與機制辨識結合；限制則包括媒體內容與特定介面情境，且不同語言、文化與技術內容可能有不同邊界。

## 研究證據怎麼讀

- 自然資料顯示可讀、句法簡單、熟悉與具體語言與持續注意正相關。
- Study 2 支持特定情緒語言的因果作用；Study 3 支持偶發情緒狀態對持續注意的作用，不能把兩者都寫成文本語言操弄。
- 研究強調 sustained attention 與 clicks、likes、shares 不同，不能互相替代。

## 不要這樣誤讀

::: danger 常見誤讀
「越簡單越好。」必要的技術精確度不能被刪除；目標是降低不必要的處理成本。
:::

::: danger 常見誤讀
「焦慮語言能提高注意，所以應大量使用恐懼。」原文指出：增加廣告中的焦慮可能維持注意力，卻可能損及品牌資產（brand equity）；在內容推薦上，以持續注意為目標的演算法可能讓使用者被餵食源源不絕的焦慮資訊，提高社群整體的負面語氣。
:::

## 與其他章節的連結

- [第 5 章](/part-1/chapter-05)：情緒和社會線索可共同影響注意與順從。
- Berger 等人的簡化模擬顯示：若使用者對焦慮內容有較高偏好（N(1,1)），以持續注意為目標的推薦演算法在第 10 輪可使參與率達 64%，但被推薦內容的平均焦慮分數升至 .63（起始 .50）。此結果針對推薦演算法，並非 GenAI 改寫文字的證據。

## 本章收束

- 先決定你要的是點擊、分享還是持續閱讀。
- 具體、熟悉、句法清楚的語言通常更有利於持續注意。
- 情緒效果要看喚起與不確定性，並與品牌與社會後果一起評估。

## 思考與練習

1. 把一段抽象文字改成具體版本，但保留原本精確度。
2. 為什麼「確定語氣」可能提高分享卻降低持續注意？
3. 設計一個同時監測閱讀完成率、信任與焦慮的內容實驗。
