# 創新擴散：好產品不會自動擴散

> 採用速度取決於知覺屬性、決策流程、網絡、意見領袖與制度

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>相對優勢</strong> | Relative Advantage | 創新被認為比既有方案更好的程度。 |
| <strong>相容性</strong> | Compatibility | 創新被視為與潛在採用者既有價值、過去經驗與需求一致的程度。 |
| <strong>複雜性</strong> | Complexity | 被認為難以理解或使用的程度；通常與採用速度負相關。 |
| <strong>可試用性</strong> | Trialability | 能否在有限風險下先行試用。 |
| <strong>可觀察性</strong> | Observability | 創新結果對他人可見的程度。 |

## 1. 擴散的四個元素

依本章所用二手讀本對 Rogers 的轉述，擴散是創新經由特定溝通渠道、隨時間在社會系統成員之間被溝通的過程。四個元素是創新、溝通渠道、時間與社會系統；它們提醒我們，同一創新在不同制度、網絡與時點可能呈現不同軌跡。

## 2. 五項知覺屬性

| 屬性 | 採用判斷 | 可觀察問題 |
|---|---|---|
| <strong>相對優勢</strong> | 它比目前做法好在哪？ | 利益是否對使用者而非設計者有意義？ |
| <strong>相容性</strong> | 它是否符合現有生活與價值？ | 需要改變多少習慣或身份？ |
| <strong>複雜性</strong> | 學會與使用是否困難？ | 錯誤成本、步驟、語言與支援如何？ |
| <strong>可試用性</strong> | 能否小規模、可逆地嘗試？ | 是否可先試後承諾？ |
| <strong>可觀察性</strong> | 結果能否被可信地看見？ | 他人的成功是否可見且可歸因？ |

## 3. 採用不是一次決定，而是一段歷程

創新決策常經過知識、說服、決定、實施與確認。讀本依經典框架指出，大眾媒體往往較能快速建立知識，人際渠道對評價與說服常更重要；但渠道作用仍取決於創新、受眾與社會系統，不能把階段和渠道一對一固定配對。採用後也可能中止，故「下載／購買」不是終點。

五類採用者依「創新性」（相對系統內其他成員較早採用新觀念的程度）劃分，並以常態分布的平均數與標準差切分。Rogers 的整理指出，較早採用者平均教育程度與社經地位較高，並在人格變項與溝通行為上和較晚採用者不同；但這類概括具情境依賴性（見 Belcher 案例），不宜把類別當成固定人格標籤。它們能幫助思考不同群體所需的風險證據與渠道，但不能把人永久貼標。

除五個知覺屬性外，採用速度還受創新決策類型（選擇性／集體／權威）、溝通渠道、社會系統與變革推動者努力影響，但過去研究多集中於五屬性。預防性創新擴散較慢；過度採用指專家認為不應採用卻被採用的創新；中止分為替代性與幻滅性兩類，較晚採用者較易中止。

::: tip 從個人到系統
個人的採用門檻會受到近端網絡影響；當系統中採用者達到臨界量，後續擴散可能變得自我維持，尤其是具有網絡效應的互動型創新。
:::

## 4. 經典框架的批判性閱讀

模組讀本不只摘要 Rogers，也指出擴散研究常帶有「創新必然是好事」的偏見。並非所有人都應採用，也可能出現過度採用、不平等後果、權威推動與在地脈絡錯配。

讀本以小兒麻痺疫苗等案例質疑把早期採用者一律描述為社經地位較高者；這是二手教材中的批判性例證，不宜外推為對所有創新的普遍反命題。 讀本引用 Belcher（1958）：Georgia 中部 701 戶中，最早採用疫苗的是低社經、低教育程度的非裔家庭。讀本作者提出若干合理詮釋，但強調重點是：脫離情境測得的因素不足以解釋擴散。讀本並批評 Rogers（1962）曾把 Belcher 錯列為支持「早期採用者社經地位較高」的研究（第二版已更正）；此為讀本作者的指控，不是 Rogers（2003）的內容。擴散分析仍應同時問：誰受益、誰承擔成本、誰決定推廣方向。

## 不要這樣誤讀

::: danger 常見誤讀
「創新者一定最好、落後者一定保守。」類別只描述相對採用時間；晚採用可能是資訊、成本或風險管理上的合理選擇。
:::

::: danger 常見誤讀
「找到意見領袖就能讓產品擴散。」讀本整理：意見領袖相較追隨者有更多大眾媒體接觸、較世界性、與變革推動者接觸較多、社會參與與社經地位較高、較具創新性；他們比追隨者更遵守系統規範，而在偏好變革的規範下特別創新。同質性網絡雖使溝通較有效，也可能成為創新在不同社經位置間流動的隱形障礙。
:::

## 本章收束

- 好產品仍需正確渠道、社會證據、時間與可逆試用。
- 採用者類別以相對採用時間劃分，不等於穩定人格標籤；讀本仍報告較早採用者在人格、社經與溝通行為上的平均差異。
- 擴散速度之外，必須評估中止、後果與不平等。
