# 選擇架構：一個按鈕、順序與拆分方式如何改變採用

> 整合選項、習慣線索與「無預設的預設」能提高行動，也可能降低覺察

| 項目 | 內容 |
|---|---|
| <strong>原始文本</strong> | Reeck, C., Posner, N. A., Mrkva, K., &amp; Johnson, E. J. (2023), “Nudging App Adoption.” |
| <strong>文本性質</strong> | 六個預註冊實驗（n=5,968）＋一個大型場域實驗（n=594,997）。 |
| <strong>本章核心問題</strong> | 不改變價格與實際預設，只改介面呈現，真的能改變 App 採用嗎？ |
| <strong>一句話答案</strong> | 可以。選項整合可減少多次決策造成的噪音；符合習慣的顏色可加快反應；像預設般的措辭也可提高啟用。但各機制不同，且透明度與自主性必須被保護。 |

辨識三種選擇架構介入；理解 support theory 與習慣線索；解讀實驗與場域證據；評估選擇架構的透明度與知情選擇。
:::

## 關鍵名詞

| 名詞 | 英文 | 本章定義 |
|---|---|---|
| <strong>選擇架構</strong> | Choice Architecture | 在不移除選項下，設計選項呈現與決策流程。 |
| <strong>整合效應</strong> | Integration Effect | 把多個功能決策合併為較少選擇後，整體採用提高。 |
| <strong>習慣線索</strong> | Habit Cue | 與既有數位操作習慣相符的顏色、位置或措辭。 |
| <strong>無預設的預設</strong> | Defaultless Default | 實際未改變不作答的結果，但讓某選項看起來像常見預設路徑。 |
| <strong>決策噪音</strong> | Decision Noise | 在多個獨立決策中，隨機或不穩定作答累積，使至少一項被停用的機率上升。 |

## 1. 三種低成本介入

| 介入 | 設計方式 | 主要機制 | 倫理注意 |
|---|---|---|---|
| <strong>整合</strong> | 把多個功能決策合成一個選擇 | 減少多次選擇造成的決策噪音；降低個別功能的顯著性／覺察 | 可能讓人低估啟用範圍 |
| <strong>顏色（位置另行檢驗）</strong> | 讓偏好選項符合常見「繼續」按鈕習慣 | 顏色效果與習慣、較快反應相符；位置主效果不顯著。Exp. 2：opt-out 措辭單獨使啟用率由 56% 升至 69%，加上慣用顏色／位置升至 82%。Exp. 4：藍色按鈕 88% vs 灰色 83%（p = .015），位置無顯著效果（右 87%／左 84%，p = .116）；顏色效果經決策時間中介顯著、經感知顯著性中介不顯著；Exp. 5 另發現顯著性有獨立效果。因此顏色的效果量遠小於 Exp. 1 完整 opt-out 呈現的差距，且不宜解讀為單一機制。 | 不得偽裝或刻意誤導 |
| <strong>措辭</strong> | 把啟用寫得像標準前進路徑 | 預設感但不改變真正預設 | 需保留清楚拒絕與說明 |

## 2. 為何把選項拆開反而降低採用

支援理論指出，把一個整體類別拆成多個項目，會提高各項目的可得性與顯著性。在 Experiment 6 中，將功能資訊分散到多個畫面，提高了受試者對個別功能的覺察，而較高覺察與較低的全部啟用率相關；透過「風險疑慮」的間接效果較小且不顯著。

此外，將一個全有或全無的選擇拆成多個需分別記錄的選擇，也降低全部啟用率，顯示多次選擇造成的決策噪音可部分（但非完全）解釋整合效應。這不代表整合一定更好：Experiment 6 同時顯示，整合可能使人較不清楚自己啟用了多少功能，採用率與知情程度可能出現張力。

## 3. 效果有多大，能否外推

實驗情境以新冠暴露通知 App 為主（Exp. 1、2、4），另有健康／健身 App（Exp. 5–6）與娛樂業求職頁面的場域實驗（Exp. 3）；樣本為美國線上樣本。作者預期結果可推廣到更多數位情境，但尚待驗證。第一個實驗中，像 opt-out 的呈現使完整啟用從約 28% 提高到 79%；整合也由約 49% 提高到 59%。這些數字屬特定實驗，不應直接當成所有 App 的通用 lift。

場域 Experiment 3 在娛樂業求職頁面，以 594,997 次頁面造訪進行藍色／灰色按鈕 A/B 測試；量到的是「view all details」點擊率（藍色 12.7%，灰色 9.4%），不是 App 安裝或功能啟用。 作者提醒顏色的意義可能因文化或使用者習慣不同；此為用戶端 A/B 測試，同一人換裝置仍可能被重複計入，但 9,000 多次的點擊差距使此影響不大（fn.1）。整體研究亦檢查不同人口、態度與政治立場的子群；作者另指出，偏好非常穩固或領域知識很高者可能較不受影響。

::: tip 漏斗定位
廣告與促銷較常把人帶進漏斗；選擇架構是在使用者已開始行動後，協助或阻礙他完成。不要用介面 nudge 掩蓋價值不足。
:::

## 4. Nudge 與 dark pattern 的倫理邊界

選擇架構不可避免，但設計可以更透明或更操控。（教材自編檢核框架，非原文內容）判斷邊界可問：資訊是否對稱？拒絕是否同樣可見？選擇是否容易撤回？設計是否符合使用者利益？是否衡量理解與後悔，而不只看轉換？

當整合會降低對功能數量的覺察時，設計者應增加摘要、逐項管理與後續可逆性。有效的 nudge 不應靠隱藏代價。

## 研究證據怎麼讀

- 六個實驗預先註冊，另有大型場域實驗；除 Experiment 3 的場域 A/B 測試外，多數實驗使用仿真的 App 介面。Experiment 1 的決策後果極低，作者因此在補充實驗加入誘因並複現結果（p.516）；研究同時檢驗選項整合、措辭、顏色與位置。
- Experiments 4–5 顯示，藍色按鈕效果與較快決策時間及自陳的藍色按鈕習慣相符；Experiment 4 的位置主效果不顯著；Experiment 5 也發現視覺顯著性有獨立效果。因此，不能把所有效果只歸因於顯著性，或只歸因於習慣。
- 作者指出：結果可能不適用於偏好強而穩固者，領域知識很高者也可能較不受選擇架構影響；整合可能使消費者較不知道自己啟用了多少功能；並提到 FTC 對訂閱註冊須透明、易取消的新指引（針對「sludge」）與歐洲主管機關的關注。

## 不要這樣誤讀

::: danger 常見誤讀
「整合選項一定改善 UX。」它可能提高完成率，卻降低對已啟用功能的認知。
:::

::: danger 常見誤讀
「沒有改真正預設就不涉及倫理。」措辭、顏色與位置仍能強力引導；透明度與撤回權同樣重要。
:::

## 本章收束

- 流程設計本身就是行為介入。
- 提高採用與保護知情選擇必須同時衡量。
- 實驗中的巨大 lift 不能直接搬到其他 App；先驗證情境與機制。

## 思考與練習

1. 畫出一個 App onboarding，標出每個決策點的摩擦與資訊價值。
2. 設計一個「整合但不降低知情」的介面方案。
3. 為實驗設定採用率以外的三個 guardrail。
